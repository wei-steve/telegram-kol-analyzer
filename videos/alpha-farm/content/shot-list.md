# 《Alpha 牧场》镜头表

版本：已锁定旁白、字幕与动画的 180 秒时间规划
画幅：1920 × 1080，30 FPS
说明：英雄帧是每场信息最完整、最适合静态审阅的画面；所有主内容先按英雄帧布局，再添加入口动画。场间统一使用数据推流、扫描线或界面推移转场，不提前清空上一场。

## 1. 00.0–15.0｜开场与片名

- 旁白：介绍“十几个 KOL 全天寻找机会”，并定义《Alpha 牧场》是把 Telegram 策略送入 AI 流水线的项目。
- 英雄帧（约 10.5 秒）：中央为紫色 AI 核心，外围 12 个真实或占位 KOL 头像全部点亮；消息粒子沿连线汇入核心；片名和副标题完整出现。
- 屏幕文字：`我没有雇交易员`、`10+ KOL ONLINE`、`《Alpha 牧场》`、`让 KOL 提供 Alpha，让 AI 负责执行`。
- 素材：KOL 头像墙、Telegram 消息卡片轮廓、Alpha 牧场字标、AI 核心矢量图形。
- 入口动画：0.2 秒后头像分三组错峰唤醒；数据线逐段描边；消息卡沿路径进入；片名从轻微色差脉冲中锁定；副标题最后淡入。
- 转场（14.2–15.0）：一条横向扫描线把头像费用标签化，数据推流进入成本墙。

## 2. 15.0–33.0｜上万美元的信息门槛

- 旁白：每个优质 KOL 群约 `$1,000 / 半年`，十几个群形成上万美元门槛；低成本信息聚合渠道打通入口。
- 英雄帧（约 29.0 秒）：左侧 10+ 个头像卡各带 `$1,000 / 6个月`，中央公式累加为 `$10,000+ / 6个月`，右侧“低成本信息聚合渠道”汇入 Alpha 牧场。
- 屏幕文字：`$1,000 / 6个月`、`× 10+ KOL`、`= $10,000+ / 6个月`、`低成本信息聚合渠道`；角落小标签 `信息搬运工：通路已建立`。
- 素材：头像缩略图、费用卡、确定性数字滚动组件、聚合管线图标。
- 入口动画：费用标签按固定顺序逐个翻牌；乘数和总额从 0 确定性滚动；“搬运工”标签以克制的小型状态提示出现；连线汇入单一入口。
- 转场（32.7–33.3）：成本公式压缩为一枚数据包，沿蓝色管线进入系统流程图。

## 3. 33.0–46.0｜系统流水线

- 旁白：消息不直接照抄；系统把自然语言转换成可检查、可计算、可拒绝的执行语言。
- 英雄帧（约 44.0 秒）：五个节点全部可见并完成连接，当前消息卡停在“风控计算”，已通过节点显示安全绿色。
- 屏幕文字：`Telegram → AI 理解 → 规则过滤 / 风控计算 → Deepcoin 执行 → 持仓保护`、`不是复制，是理解 + 约束 + 执行`。
- 素材：Telegram 卡、AI 扫描框、盾牌/计算节点、Deepcoin 抽象订单卡、持仓保护环。
- 入口动画：消息卡先进入；五个节点依次从不同方向落位；连接线随验证进度描边；通过后的节点才切换为安全绿色。
- 转场（45.7–46.3）：镜头沿数据连线反向拉远，连线分叉成为 KOL 头像墙的网格。

## 4. 46.0–67.0｜KOL 阵容与代表策略

- 旁白：说明数据库观察窗口内“聊天多、入场信号少”，并介绍大镖客、比特币飞扬、峰哥、比特智智哥的不同表达和管理风格。
- 英雄帧（约 60.0 秒）：12 个头像组成阵容墙；四位重点 KOL 放大置于前排，每人旁边有一张脱敏策略卡和风格标签。
- 屏幕文字：`数百条聊天 ≠ 数百条策略`、`数据库内信号相对稀疏`；`大镖客｜BTC 区间 / 固定止损 / 多目标`；`比特币飞扬｜极简字段`；`峰哥｜ETH 现价 / 轻仓提示`；`比特智 智哥｜左侧挂单 / 后续管理`。
- 素材：4 位已批准 KOL 的真实头像与脱敏消息；其余头像；候选报告中的安全摘要。不得展示胜率、收益率、群邀请链接或账号信息。
- 入口动画：全体头像以受控错峰进入；重点四人分别以卡片翻面、扫描锁定、币种切换和挂单时间线四种入口出现；消息卡逐张展开。
- 转场（66.7–67.3）：大镖客的 BTC 区间策略卡被扫描框选中，其他头像退为背景景深，扫描框扩展为 AI 解析台。

## 5. 67.0–85.0｜AI 理解策略

- 旁白：AI 提取币种、方向、入场范围、固定止损、止盈和管理指令；模糊、矛盾或归属不明时拒绝猜测。
- 英雄帧（约 83.0 秒）：左侧保留脱敏原始消息，中央扫描线经过，右侧六个结构化字段全部锁定；下方保留一条“人工复核”分支。
- 屏幕文字：`BTC`、`SHORT`、`71000–71800`、`SL 72300`、`TP 70300 / 69600 / 68900`、`管理指令`、`不确定 → 拒绝执行 / 人工复核`。
- 素材：大镖客脱敏代表消息、字段芯片、置信状态、人工复核队列卡。
- 入口动画：原始消息从 Telegram 侧滑入；扫描线从上到下扫过；字段按原文位置逐一抽取并飞入右侧槽位；复核分支在异常示例出现后再展开。
- 转场（84.7–85.3）：`SL 72300` 字段放大为红色止损刻度，价格轴变形成下一场的风险尺。

## 6. 85.0–127.0｜以损定仓

- 旁白：先定最大预设亏损 100 USDT，再以入场与固定止损的距离反推两腿数量；杠杆不改变预设风险。
- 英雄帧（约 120.0 秒）：价格尺同时显示 61,500 止损、62,000 保守入场、62,400 贪婪入场；左右两张公式卡完成计算，底部合计为 `50 + 50 = 100 USDT`。
- 屏幕文字：`最大预设亏损 100 USDT`、`每腿风险 50 USDT`、`50 ÷ (62,000 − 61,500) = 0.1 BTC`、`50 ÷ (62,400 − 61,500) ≈ 0.0556 BTC`、`杠杆影响保证金占用，不改变预设风险`、`演示数字`。
- 素材：价格尺、风险预算仪表、公式卡、仓位结果卡；实际资金规模不得出现。
- 入口动画：先出现 100 USDT 风险上限；预算分为两个 50；价格刻度依次锁定；减法距离沿价格尺描边；除法结果逐位落下；最终合计盖上“最大预设亏损”绿色校验章。
- 转场（126.7–127.3）：两张公式卡沿各自价格刻度分叉，直接成为“双腿入场”的两条路线。

## 7. 127.0–147.0｜贪婪腿与保守腿

- 旁白：范围价拆为两条并列路线；贪婪腿靠近易成交一侧优先参与，保守腿等待更好价格，两者分别管理风险和订单状态。
- 英雄帧（约 140.0 秒）：同一价格区间内两条路线并列；左侧“贪婪腿 62,400 / 50 USDT / 0.0556 BTC / READY”，右侧“保守腿 62,000 / 50 USDT / 0.1 BTC / WAITING”。
- 屏幕文字：`贪婪腿｜更易成交 / 优先参与`、`保守腿｜更好的价格 / 较低成交概率`、`独立入场价`、`独立风险预算`、`独立仓位`、`独立订单状态`。
- 素材：区间价格带、双路线节点、两腿订单卡、等待与就绪状态图标。
- 入口动画：价格范围先展开；中心路径一分为二；贪婪腿沿较远路径滑入并停在等待位；保守腿沿较短路径进入就绪位；四项字段逐一挂接。
- 转场（146.7–147.3）：两条路线在订单入口前合流，一张缺少止损字段的匿名策略卡突然阻断流动，画面染入风险红。

## 8. 147.0–163.0｜安全底线

- 旁白：自动化不放松底线；缺少固定止损时无法计算仓位并立即拒绝交易。

- 屏幕文字：`STOP LOSS — MISSING`、`NO STOP, NO TRADE`、`没有止损，就没有仓位`、`没有止损，就不执行交易`。
- 素材：匿名无止损策略演示卡、风险公式断路状态、安全门、拒绝执行状态章。
- 入口动画：策略卡进入；字段槽依次检查；止损槽返回空值；公式线路断开；红色安全门自上下两侧闭合并盖下拒绝章。
- 转场（162.7–163.3）：安全门闭合面变为近黑画布，一束紫蓝数据光从门缝中展开为片尾 AI 核心。

- 片尾处理（179.2–180.0）：仅最终场允许整体轻柔淡出至 `#070A12`，音乐保留短尾。

- 场景边界严格为：`00–15 / 15–33 / 33–46 / 46–67 / 67–85 / 85–127 / 127–147 / 147–163 / 163–180` 秒。
