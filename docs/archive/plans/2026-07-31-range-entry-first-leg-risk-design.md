# 区间入场第一腿仓位优化设计

## 目标

提高只成交第一条入场腿时的仓位和潜在盈利，同时保持两条腿全部成交后止损的预估总亏损不超过原策略风险预算。

## 范围

- 只改变部署后新生成的真实区间入场草稿。
- 不修改历史持仓、已提交挂单、已持久化的待执行草稿或历史数据。
- 不改变单价入场的单腿 100% 风险预算逻辑。
- 不增加 shadow 流程、后台任务、数据库迁移或历史回填。
- 不改变入场价、止损价、止盈计划、策略归属或提交流程。

## 仓位分配

对两条真实区间入场腿，以最终规范化入场价计算到止损的绝对距离：

```text
d1 = abs(first_entry_price - stop_loss)
d2 = abs(second_entry_price - stop_loss)
```

使两腿仓位相等时，第一腿应承担的原始风险比例为：

```text
raw_first_share = d1 / (d1 + d2)
```

最终比例限制为 50% 至 65%：

```text
first_share = clamp(raw_first_share, 0.50, 0.65)
second_share = 1.0 - first_share
```

现有仓位公式保持不变，仅将每腿的 `allocation_pct` 从固定 50% 替换为上述结果。由于两腿风险份额之和仍为 100%，取整前的总预计止损亏损仍等于策略风险预算。

## 安全与失败处理

- 缺少止损时保留现行 50/50 分配，因为无法证明动态风险比例。
- 任一腿与止损距离非正数时继续使用现有校验拒绝草稿，不引入隐式回退仓位。
- 交易所合约数量步长和最小数量规则保持不变，现有向下取整保证实际预计风险不高于理论预算。
- 已保存草稿在提交时仍优先使用其自带的 `order_legs`，因此部署不会重算旧订单。

## 验证与部署

- 单元测试覆盖普通动态等仓位、65% 上限、缺失止损回退 50/50、单价入场不变和总风险不变。
- 运行定向下单构建器测试，再运行相关自动交易与提交测试。
- 推送到 `codex/deepcoin-auto-trading-v1` 后，只在服务器证明当前没有时效性策略操作时拉取、重装可编辑包并短暂重启 `telegram-kol.service`。
- 重启后验证服务健康和日志，不提交测试订单。
