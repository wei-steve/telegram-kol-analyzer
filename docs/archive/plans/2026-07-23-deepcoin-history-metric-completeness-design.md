# DeepCoin 历史仓位指标完整性设计

## 目标

让每张历史仓位卡固定呈现 DeepCoin App 的五项成交指标：开仓均价、平仓均价、已实现盈亏、最大持仓量、已平仓量。

## 决策

采用固定指标布局。已有真实成交或仓位数据时照常展示；数据不存在时统一显示 `--`。不以策略的入场区间、止盈或止损建议冒充实际成交数据。

## 展示规则

- 首行三列：开仓均价、已实现盈亏、最大持仓量。
- 次行两列：平仓均价、已平仓量。
- 已实现盈亏为正时为绿色，负值为红色；缺失值保持中性灰色。
- 最大持仓量和已平仓量共享当前可核验的仓位数量文本；无数量时显示 `--`。
- 时间与策略归属区保持现有结构和排序，避免影响其他三个交易标签页。

## 验证

渲染测试覆盖：五个标签在真实数据不全时仍全部出现、缺失值显示 `--`、真实盈亏保留数值及正负颜色类。现有 Web 页面和资产冒烟测试继续通过。
