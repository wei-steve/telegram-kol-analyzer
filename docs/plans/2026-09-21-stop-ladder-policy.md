## 1. 用户原话（2026-09-21）

> 如果入场价格是范围值，只进了第一条腿，未达到任何止盈时，止损价就是策略的止损价。如果两条腿进场，未达到任何止盈时，止损价就是策略的止损价。
> 如果只有第一条腿，并且未达到任何止盈，收到保本消息，调整止损价为策略入场价。如果两条腿都入场，并且未达到任何止盈，收到保本消息，调整止损价为策略入场价的平均值。
> 如果达到第一止盈价并且实际止盈，自动调整止损价为策略入场价。
> 如果达到第一止盈价并且实际止盈，收到移动止损或者保本消息，自动调整止损价为策略入场价。
> 如果达到第二止盈价并且实际止盈，自动调整止损价为策略第一止盈价。
> 如果达到第二止盈价并且实际止盈，收到移动止损或者保本消息，自动调整止损价为策略第一止盈价。
> 如果达到第三止盈价并且实际止盈，自动调整止损价为策略第二止盈价。
> 如果达到第三止盈价并且实际止盈，收到移动止损或者保本消息，自动调整止损价为策略第二止盈价。

> （目标止损价与市场价冲突时）一般代表价格对我们不利，应该用市价平仓。

## 2. 规则表

"策略入场价"按已上线的 R1 取：只有第一腿有仓位 → 策略第一腿价格（空单 = 入场区间下沿，多单 = 上沿）；两条腿都有仓位 → 区间简单中点；
策略只有单一入场价 → 该价。**一律取策略的价格，不取我们自己的成交价。**

| 已"实际止盈"的最高档位 | 没有消息时（自动） | 收到"移动止损 / 保本"类消息时 |
|---|---|---|
| 无 | 止损 = 策略止损价（不动） | 止损 → 策略入场价 |
| 第一档 | 止损 → 策略入场价 | 止损 → 策略入场价 |
| 第二档 | 止损 → 策略第一止盈价 | 止损 → 策略第一止盈价 |
| 第三档 | 止损 → 策略第二止盈价 | 止损 → 策略第二止盈价 |

通式：已实际止盈到第 N 档 → 止损目标 = 第 N−1 档的策略价，其中"第 0 档"= 策略入场价。消息只决定**是否现在就动**（未止盈时），不改变目标价。

- **"实际止盈"**= 该档止盈单在交易所**真实成交**（用户已确认这个判据），不是价格碰到、也不是 KOL 说到了。
- **目标价与现价冲突**（多单：目标 ≥ 现价；空单：目标 ≤ 现价）→ **市价平仓**，没有中间回落。
- 此前一句"到了止盈 1 就把止损移到止盈 1"被本表取代（到第一档 → 策略入场价；到第二档才移到第一止盈价）。
- 继续有效的约束：只收紧不放宽（已有止损更保护则保留）；不开仓、不加仓；自动交易开关不动；`adjust_stop_loss`（消息明确给新止损价）不受本表影响。

## 3. 与现状的差距（2026-09-21 核实）

1. **系统今天不知道"哪一档止盈实际成交了"。** `strategy_lifecycles.filled_tp_index` 只由模拟盘的价格监控 `lifecycle_monitor` 维护；
   最近 60 个带真实仓位的策略该字段全部为 −1。需要一个以交易所证据为准的"已成交止盈档位"判定（保护账本 / 止盈单成交 / 仓位数量变化）。
2. **"自动"那一列今天没有在运行。** TP1 成交后自动保本（`break_even_convergence`）全历史只有 2 条记录（08-03，blocked），按仓位 ID 硬编码放行，
   "挂不上就市价全平"分支 2026-09-11 未获批准（放行名单为空）。它也只覆盖第一档，没有第二、第三档。用户本次的规则等于批准了全平分支并要求扩展到三档。
3. **"收到消息"那一列**：未止盈与第一档两行已由今天上线的 R1 覆盖（目标 = 策略入场价）；第二、第三档两行需要在 `break_even_reference` 上加阶梯。
4. **复合指令（减仓后保本）整条链路在生产上 0 成功**（上游两个拦截：保护单与账本对不上、撤已兑现止盈单重试耗尽），阶梯规则要生效必须先打通。
5. **目标价冲突 → 市价平仓**：`move_stop_to_break_even` 已是如此；复合指令的同等行为已实现未部署（`dde69b31`）。
