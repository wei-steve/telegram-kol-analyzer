# Alpha 牧场视频：群组隔离表达修订

## 目标

修正 KOL 介绍段中“智哥负责管理挂单”的歧义，避免观众误以为某位 KOL 会跨群管理其他来源的策略或订单。

## 已批准方案

- 将“智哥负责管理挂单”改为“智哥常发布限价挂单和后续更新”，描述其群内消息特点，不赋予跨群管理职责。
- 在 KOL 阵容场景增加群组隔离提示：`每个 KOL 群独立解析、独立风控、独立执行`。
- 旁白明确说明：所有群组分别运行，策略、订单和仓位互不干扰。
- 保持视频总时长 3 分钟，不新增场景；通过压缩原 KOL 介绍文案容纳隔离说明。

## 修改范围

- KOL 阵容场景中的智哥风格标签和隔离提示。
- 该场景对应的旁白、字幕与分镜文档。
- 重新生成中文女声并渲染最终 MP4。

## 验证

- HyperFrames lint、check 与 15 点布局检查通过。
- 抽查 KOL 场景，确认智哥文案不再包含“负责管理”。
- 成片包含 H.264 视频和 AAC 音频，时长保持 180 秒。
